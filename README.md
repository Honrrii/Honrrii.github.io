# Henry Valladares — Portfolio

A responsive, dependency-free portfolio prepared for GitHub Pages.

## Publish to Honrrii.github.io

Copy these three files into the publishing root of your existing `Honrrii.github.io` repository, replacing its old `index.html`:

- `index.html`
- `styles.css`
- `script.js`

Keep the files together. Use the repository's existing GitHub Pages publishing configuration. No build step is required.

## Preview locally

Open `index.html` directly in a browser, or run `node preview.cjs` and visit `http://localhost:4173`.

## Included

- All seven original projects and the original email, GitHub, and LinkedIn destinations.
- Responsive layout, pointer-reactive point cloud, and animated project detail panels.
- Native keyboard-accessible disclosures, visible focus, skip navigation, and reduced-motion support.
- A pause control for animation. The point cloud stops rendering when offscreen or in a background tab.
- Content and project disclosures remain usable without JavaScript.

Google Fonts enhances the typography when online; local fallback fonts are provided. The animated point cloud is an abstract visual, not live project telemetry.

The redesign has been tested in Microsoft Edge at widths of 320, 390, 768, 1024, and 1440 pixels, including panel opening/closing, keyboard activation, networking links, reduced motion, and JavaScript-disabled content.

This folder contains the completed redesign. It has not been published to the live GitHub Pages site.
