Flagship Project

OMNI — Autonomous Engineering Command

A local FastAPI and React-based engineering system that converts natural-language robotics ideas into structured design artifacts, validation reports, ROS2-oriented outputs, and CAD concept-generation scripts. Features an "Echo" agent that translates rough ideas into complete engineering missions.

Problem Solved

Early robotics and mechatronics projects begin as vague ideas. OMNI organizes those ideas into requirements, architecture plans, validation checkpoints, and implementation-ready outputs — reducing planning friction from hours to minutes.

Project 07
AI Research · GPU Systems

GVProf Agent Skill — GPU Profiling Research

Ongoing UC Merced research building an LLM agent skill for GVProf, a CUDA/PyTorch GPU value-redundancy profiler. Deployed and validated GVProf against CUDA sample workloads, then built a structured layer converting raw profiler CSV output into JSON and human-readable optimization reports. Currently mapping PC-offsets to source lines via -lineinfo, cuobjdump, and nvdisasm.

CUDA PyTorch LLM Agents Python GPU Profiling
