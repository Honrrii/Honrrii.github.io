01
Multi-Agent AI · Robotics Builder
Flagship Project

OMNI — Autonomous Engineering Command

A local FastAPI and React-based engineering system that converts natural-language robotics ideas into structured design artifacts, validation reports, ROS2-oriented outputs, and CAD concept-generation scripts. Features an "Echo" agent that translates rough ideas into complete engineering missions.

Problem Solved

Early robotics and mechatronics projects begin as vague ideas. OMNI organizes those ideas into requirements, architecture plans, validation checkpoints, and implementation-ready outputs — reducing planning friction from hours to minutes.

Python FastAPI React ROS2 Fusion 360 Multi-Agent LLM GitHub
02
Computer Vision · Metrology

AI-Assisted SEM Measurement Tool

Desktop computer vision tool for SEM image segmentation, inspection, calibration, and pixel-to-nanometer measurement workflows. Combines SAM segmentation with precision calibration into a repeatable, auditable metrology pipeline.

Python PyQt OpenCV Segment Anything Flask

Robotics Simulation

ROS2 Robotic Arm Simulation

Full robotic arm simulation environment using ROS2, Gazebo, and RViz. Covers URDF modeling, joint-position control, transform trees, and controller debugging — enabling hardware validation before physical deployment.

ROS2 Gazebo RViz URDF Linux
