01 / MULTI-AGENT AIFLAGSHIP

OMNIAutonomous Engineering Command

A local engineering system that turns natural-language robotics ideas into structured designs, validation reports, ROS2 outputs, and CAD concept-generation scripts.

PythonFastAPIReactROS2Fusion 360Multi-Agent LLMGitHub
Inside the project +

The “Echo” agent translates rough ideas into complete engineering missions. Built with FastAPI and React, OMNI connects requirements, architecture plans, validation checkpoints, and implementation-ready outputs.

Problem solved. Early robotics and mechatronics projects begin as vague ideas. OMNI reduces planning friction from hours to minutes by organizing those ideas into a structured engineering process.

CURRENT RESEARCH · UC MERCED

GVProf Agent Skill — GPU Profiling Research

AI Research · GPU Systems+

Ongoing UC Merced research building an LLM agent skill for GVProf, a CUDA/PyTorch GPU value-redundancy profiler. Deployed and validated GVProf against CUDA sample workloads, then built a structured layer converting raw profiler CSV output into JSON and human-readable optimization reports. Currently mapping PC-offsets to source lines via -lineinfo, cuobjdump, and nvdisasm.
